# Pak Resto Unikom

Aplikasi atau sistem restoran yang dikembangkan untuk lingkungan Universitas Komputer Indonesia (Unikom). Proyek ini bertujuan untuk menyediakan solusi digital dalam pengelolaan restoran, mulai dari pemesanan, manajemen menu, hingga layanan pelanggan.

## Fitur Utama

- Sistem pemesanan digital
- Integrasi dengan lingkungan kampus Unikom
